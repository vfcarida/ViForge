# ViForge Related Projects and Comparative Analysis

| Project | Primary Focus | Training Methods | Evaluation Harness | Pareto / Cost Engine | Distinguishing Advantage of ViForge |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TRL (Hugging Face)** | Training library | SFT, DPO, PPO, GRPO | None (relies on Lighteval) | No | ViForge integrates pre-flight profiling, data contamination shield, and Pareto frontier optimization into a single declarative pipeline. |
| **Axolotl** | Configuration-driven trainer | SFT, LoRA, QLoRA, DPO | None | No | ViForge couples training with benchmark evaluation, generalist retention tracking, and Capability-per-Dollar economic scoring. |
| **EvalPlus** | Python code benchmark | N/A | HumanEval+, MBPP+ | No | ViForge embeds EvalPlus directly into its multi-stage specialization workflow. |
| **SWE-bench** | SWE issue resolution | N/A | Docker execution | No | ViForge includes an isolated sandbox runner compatible with SWE-bench Lite. |
| **Stanford HELM** | Holistic evaluation | N/A | Multi-metric evaluation | No | ViForge links evaluation results directly to AWS instance training costs to compute Capability-per-Dollar. |
